# Neural Network Hyperparameter Tuning Pipeline with Keras Tuner

This project provides a clear, step-by-step practical implementation of neural network architecture optimization using Keras Tuner.

## 📈 Tuning Stages Included:
1. *First Model (Basic Baseline)*: Building a simple feedforward baseline network.
2. *Second Model (Tuning #Neurons)*: Evaluating the optimal width (number of hidden units) for the hidden layers.
3. *Third Model (Tuning #Layers)*: Evaluating depth by searching for the optimal number of hidden layers.
4. *Fourth Model (Complete Search Space along with Dropout): A comprehensive joint search optimizing depth, width, activations, and optimizers, incorporating **Dropout* regularizations to handle overfitting.

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- Keras Tuner
- Scikit-Learn
- Matplotlib
